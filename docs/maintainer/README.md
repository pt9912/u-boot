- [`branch-protection.md`](branch-protection.md) — Einrichtung der Required Status Checks für `main`.
- [`releasing.md`](releasing.md) — Release-Ablauf (Tag, `publish`, GHCR, Binaries, Pakete, Homebrew-Tap, Fehlerbilder).
